# 0001 — Target MCP 2026-07-28, stateless, on SDK v2

Status: accepted · 2026-11-10

## Context

MCP 2026-07-28 removes sessions, the `initialize` handshake and `Mcp-Session-Id`; list results
must not vary per connection; every request carries its version in `_meta`. v1 is built on
per-session servers (SDK 1.x, spec 2025-11-25). The MCP TypeScript SDK v2
(`@modelcontextprotocol/server` and friends) implements 2026-07-28; SDK 1.x will not.

## Decision

v2 implements MCP 2026-07-28 on SDK v2 and keeps no protocol state between requests. Per-user
differences come from the request's `cds.context.user`. Whether and how 2025-11-25 clients are
served is decided by the M4 spike (ADR 0010).

## Consequences

- No session manager, no eviction, no session/user binding bugs (v1 issue #4 disappears).
- Horizontal scaling needs nothing extra.
- Elicitation becomes Multi Round-Trip Requests (`input_required`).
- We depend on SDK v2's packages: `server`, `node`, optionally `express`; `ext-apps` for MCP Apps.
